Tickets CE et QR codes

Créer un lot de codes pour un comité d’entreprise ou un partenaire, retrouver un code, l’annuler, et suivre leur utilisation sur les bornes, le site et au comptoir.

Octobre 2026SpaceBowling Engine

Un organisme (comité d’entreprise, mairie, partenaire) achète un lot de tickets, par exemple 1 000 parties de bowling. Le CRM génère les codes, on les lui envoie, et chaque code est suivi jusqu’à son utilisation.

Ce qu’il faut regarder est entouré en orange et numéroté. Menu Centre › Tickets CE / QR codes.

1

Les lots

Onglet Lots. Un lot = un organisme, un contenu, un nombre de codes et une date de fin.

  1. 1
    Un lot : organisme, contenu, codes émis, utilisés, restants, date de fin, état. Un clic l’affiche en dessous.
  2. 2
    Le détail du lot : émis, utilisés, annulés, valeur restante, prix de vente à l’organisme, validité.
  3. 3
    Voir les codes, Exporter (PDF avec un QR code par page, et CSV), Suspendre (plus aucun code accepté).
  4. 4
    Nouveau lot (chapitre 2).

Les états d’un lot

OptionCe qui se passe
ActifSes codes sont acceptés partout.
ExpiréLa date de fin est passée : ses codes sont refusés.
ClosTous ses codes sont utilisés, ou il a été fermé.
SuspenduArrêté à la main : ses codes sont refusés jusqu’à nouvel ordre.
2

Créer un lot

Onglet Créer un lot (ou « Nouveau lot »). Le CRM génère les codes, signés et à usage unique.

  1. 1
    Organisme : le CE, la mairie, le partenaire.
  2. 2
    Type : Ticket CE (code imprimé) ou QR code.
  3. 3
    Contenu et nombre : ce que vaut un code : une formule de n’importe quelle activité du CRM (Bowling · 1 partie, Laser Game · …), −5 € sur une activité, ou une boisson offerte. Le code ne sert que là. Puis combien en générer.
  4. 4
    Valeur, prix facturé, fin de validité : la valeur d’un code pour le client, le prix payé par l’organisme, la date limite.
  5. 5
    Générer le lot.
  6. 6
    Ce qui se passe ensuite : l’envoi à l’organisme et la facture.
À savoir

Chaque code a son propre QR code, créé tout seul : rien à faire.

Chaque code est signé et à usage unique : une fois utilisé, il est refusé partout. Il est aussi refusé sur une borne sans réseau (il ne peut pas être vérifié).

3

Retrouver un code, sa fiche et son QR code

Onglet Liste des codes : tous les codes, tous lots confondus. Un clic sur une ligne ouvre la fiche du code.

  1. 1
    Tapez ou scannez un code (la scannette marche directement dans ce champ), ou un nom d’organisme.
  2. 2
    Filtrer par état : disponibles, utilisés, annulés.
  3. 3
    Annuler un code perdu ou volé : il sera refusé partout. « Réactiver » remet en circulation un code utilisé par erreur.

Pour un code utilisé, la liste indique quand et où (quelle borne, le site, le comptoir). Un clic sur la ligne ouvre sa fiche, à droite :

  1. 1
    Le QR code du ticket. Chaque code a le sien, créé tout seul. Il contient le code : un téléphone ou la scannette des bornes le lit.
  2. 2
    Copier le code, télécharger le QR code (image PNG, pour un courrier ou un e-mail à l’organisme), imprimer le ticket (format ticket de caisse, avec le logo).
  3. 3
    Ses informations : organisme, contenu, pour quelle activité il est valable, valeur, validité, lot (un clic l’ouvre), utilisation.
  4. 4
    Annuler ou réactiver ce code. Un code annulé est refusé partout ; réactivé, il resert une fois.
4

Suivre l’utilisation

Onglet Suivi : ce qui a été validé aujourd’hui, les tentatives refusées, et la consommation de chaque organisme.

  1. 1
    Validations d’aujourd’hui : l’heure, le lot, le contenu et le lieu de chaque code utilisé.
  1. 2
    Tentatives refusées : code déjà utilisé, expiré ou inconnu, avec le lieu. Utile en cas de litige.
  1. 3
    Consommation par organisme : codes émis, utilisés et taux d’utilisation de chaque lot.
  2. 4
    Valeur consommée : la base de la facturation à l’organisme.
5

Côté client

Sur les bornes, le ticket CE est un moyen de paiement, comme la carte et les espèces.

OùComment
Borne, toutes les activités et le barAu moment de payer, tuile « Ticket CE ou code promo » : le client scanne le QR code (ou tape le code), un ou plusieurs tickets, puis « Valider ». Ce qui reste se paie ensuite par carte ou en espèces. Avec « Payer une partie », il paie par exemple 2 joueurs sur 4 avec 2 tickets, le reste par carte. Au récapitulatif, une ligne le prévient.
SiteAu récapitulatif, bloc « Code promo / Ticket CE ».
ComptoirL’équipe scanne ou tape le code.

Le réglage (Sandbox › module › page Récapitulatif)

OptionCe qui se passe
« Tickets CE et codes promo acceptés » cochéLa tuile Ticket CE est proposée au paiement sur la borne, et le bloc sur le site (par défaut).
DécochéPas de ticket CE pour cette activité. Au bar, les tickets sont toujours acceptés.
À savoir

Un code ne sert que pour l’activité de son lot : un ticket « Bowling · 1 partie » est refusé au laser. « −5 € sur une activité » vaut partout, « Boisson offerte » au bar.

Sur la borne, les tickets sont consommés quand le client touche « Valider ». S’il part sans payer le reste, la commande est abandonnée et ses tickets redeviennent disponibles.

Un ticket couvre au plus ce qui reste à payer : la différence n’est pas rendue (la borne le signale avant de valider).

6

Si quelque chose ne va pas

Les cas les plus courants, et où regarder.

Le client voit…À vérifier
« Code déjà utilisé »Liste des codes : quand et où il a servi. Réactivez-le s’il a été utilisé par erreur.
« Code expiré » ou « lot clos »La date de fin et l’état du lot.
« Code inconnu »Une faute de frappe (lettres et chiffres), ou un code d’un autre centre.
« Pas de réseau »La borne ne peut pas vérifier le code : réessayer au retour du réseau, ou au comptoir.
« Ce code est valable seulement pour … »Le code est réservé à l’activité de son lot (sa fiche, ligne « Valable pour ») : un ticket bowling ne paie pas le laser.
